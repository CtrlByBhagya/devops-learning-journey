# Day 1 - Python Basics

## Concepts Learned

1. Variables - Used to store data.
2. Data Types - Basic types include int, float, str and bool.
3. print() - Displays output.
4. input() - Takes input from the user as a string.
5. Type Conversion - Converts values using int(), float() and str().
6. Operators - Perform arithmetic operations such as +, -, * and /.
7. String Concatenation - Joins strings using +.
8. String Replication - Repeats strings using *.
9. Comments - Add explanations to code using #.
10. len() - Returns the length of a string.
11. type() - Identifies the data type of a value.
