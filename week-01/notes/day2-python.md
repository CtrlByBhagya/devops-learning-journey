
# Day 2 - Python Basics

## Concepts Learned

### 1. Comparison / Relational Operators
- Compare two values and return a Boolean value (`True` or `False`).
- Examples: `==`, `!=`, `>`, `<`, `>=`, `<=`.

### 2. Assignment Operator
- `=` assigns a value to a variable.
- `==` checks whether two values are equal.

### 3. Boolean Operators
- Used to combine or modify Boolean conditions.
- `and` - True when both conditions are true.
- `or` - True when at least one condition is true.
- `not` - Reverses a Boolean value.

### 4. Conditional Statements
- `if` - Executes when its condition is true.
- `elif` - Checks another condition if the preceding conditions were false.
- `else` - Executes when none of the preceding conditions are true.

### 5. Loops

- `for` loop - Repeats a block of code over a sequence or range.
- `while` loop - Repeats a block of code as long as its condition remains true.
- `range(start, stop)` generates numbers from start up to, but not including, stop.
- Loop variables can be updated to control repetition.
